# Priyanshu Namdev | Portfolio 🚀

Personal developer and data science portfolio showcasing projects, verified credentials, and interactive zero-gravity physics animations. Designed with an **iOS 18 Liquid Glassmorphism** aesthetic.

🔗 **Live Portfolio:** [priyanshuxsom.web.app](https://priyanshuxsom.web.app)

---

## ✨ Features

- ** iOS Liquid Glass UI:** Custom glassmorphism design with dynamic backdrop blurs, pill badges, and smooth micro-interactions.
- **🌌 Zero-Gravity Physics Canvas:** Interactive 2D physics simulation rendering floating tech stack orbs with elastic collisions, boundary bouncing, and cursor repulsion.
- **🍱 Bento Grid Architecture:** Modular presentation of academic background at **IIT Jodhpur**, core competencies, and verified achievements.
- **📜 Interactive Credentials Showcase:** Auto-scrolling carousel with interactive modal preview, verification links, and instant credential ID copying.
- **⚡ Blazing Fast:** Built with modern web standards, optimized assets, and responsive across all device breakpoints.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern CSS3 (Custom Glassmorphism, CSS Grid & Flexbox), Vanilla JavaScript (ES6+), Canvas API
- **Build Tool & Bundler:** [Vite](https://vitejs.dev/)
- **Styling Framework:** [Tailwind CSS](https://tailwindcss.com/)
- **Hosting & Deployment:** [Firebase Hosting](https://firebase.google.com/docs/hosting)

## 💻 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation & Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/priyanshuxsom/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
